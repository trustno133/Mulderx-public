# Open redirect

Route a user-controlled navigation destination to `open-redirect` /
`open_redirect_specialist`. If the parameter is an OAuth/OIDC callback, use
the OAuth specialist as owner.

Confirm the actual `Location` and browser navigation with a harmless
controlled destination. A 3xx response alone is not impact. Check current
program policy and require a demonstrated consequence or separately evidenced
authorized chain; never use a real victim or sensitive token as a proof.
